# Brasaland public site (photo build)

This is the multi-page site with dish photos, the guest menu, locations, Brasa Points, allergens, the supplier application, and the table-request chat. English and Spanish switch in the header.

It is the build that was published on GitHub Pages, restored from commit `2465196` (`Fix supplier form asset 404s when served from the repo root`). The repository-root build copies this folder to `dist/` so Vercel serves it at `https://www.brasalandrestaurant.com`.

The later Vite app remains in `uis/website/` and is not what production publishes.
